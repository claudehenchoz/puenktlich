# SBB RABDe 500 ICN (InterCity-Neigezug): reference

44 seven-car tilting units RABDe 500 000–043, built 1999–2005 (Adtranz/FIAT-SIG, then
Bombardier/Alstom), designed by Pininfarina; active tilt up to 8°. Each unit is named after a
Swiss personality (500 000 "Le Corbusier" … 500 043 "Harald Szeemann"). Routes (2026): IC 5
Lausanne–Biel–Zürich–St. Gallen, IC 51 Basel–Biel–Lausanne, IR 57, partly IC 3 and IC 2.
