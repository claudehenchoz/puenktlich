# Pünktlich

Pünktlich - or `puenktlich` is a set of OpenTTD assets to provide Swiss trains & buses to players wanting to play the Swiss experience.

It aims to be as complete as possible (and tracks completeness against official lists).

It aims to create the best-looking trains that fit in the game.

It is a modern repository that uses modern tooling to build, process, test and release assets.

It is built for AI-assisted creation of assets.
